MASTER PROMPT — Maharudra Solar Services

Goal:
Build a responsive marketing site "Maharudra Solar Services" (Vite + React + TypeScript) with a hero, promo card (clickable PM Surya Ghar image linking to https://pmsuryaghar.gov.in/#/), a simplified solar calculator/recommendation integrated into the contact flow, a solar-only chatbot "Rudra AI", documents checklist, and a WhatsApp enquiry flow. Optimize hero assets for fast load and include a fallback for older runs.

Tech stack:
- Frontend: React (Vite), TypeScript, Tailwind CSS (or existing styling system).
- Static assets in public/.
- LLM integration: client-side stub + note to proxy key server-side (do NOT hardcode production keys in client).

Visual / UI:
- Hero: left column text; right column media panel with a responsive hero image. Default should be an optimized WebP (800px & 400px sizes via srcset/picture) named public/hero-custom-800.webp and /hero-custom-400.webp. Provide a preload for the 800w WebP.
- Promo card: use public/pm-surya-ghar.png; clicking it opens https://pmsuryaghar.gov.in/#/ in a new tab.
- Contact section (#contact): simple form with fields:
  - Name (required)
  - Mobile number (required)
  - Monthly electricity bill (optional numeric) — used to recommend system size
- Documents checklist section (replaces old calculator fields): static list of required documents for the solar scheme.
- Remove the "quick submit" duplicate; keep a single enquiry flow.
- Chat widget: "Rudra AI" floating widget — solar-only assistant. Provide quick prompts and a slight reply delay to simulate friendly chat.
- Replace any demo estimate overlay; hero should be clean and fast.

Business logic:
- Solar recommendation rules (final):
  - monthly bill 0–3000 => recommend 3 kW (sample: 6×540W panels, ~330–390 units/mo, ~4,000–4,700 units/yr, ~240–300 sq.ft)
  - monthly bill 3001–5000 => recommend 5 kW (9–10×540W, ~550–650 units/mo, ~6,600–7,800 units/yr, ~400–500 sq.ft)
  - monthly bill >5000 => recommend contacting the team for a custom plan
- On contact submit, open WhatsApp (wa.me) to +91 91124 32313 with a prefilled message: name, mobile, monthly bill, and recommendation text.

Chatbot (Rudra AI):
- Strong system prompt restricting responses to solar installation, calculations, documentation, Maharudra Solar offerings, and local incentives.
- Client-side call to completions API if API key configured; document that keys must be proxied server-side in production.
- Local fallback canned replies if API fails.
- UX: quick prompts, typing-delay (e.g., 600–900ms per reply chunk), restrict suggestions to the product/plans listed above.

Hero media & conversions:
- Source video: public/hero-video-with-audio.mp4 (user-provided) or static hero-custom.png.
- Preferred production formats: optimized WebP (static) or WebM (animation). GIF only if necessary.
- FFmpeg commands (examples):
  - PNG → WebP sizes:
    ffmpeg -i public/hero-custom.png -vf "scale=800:-1" -q:v 50 public/hero-custom-800.webp
    ffmpeg -i public/hero-custom.png -vf "scale=400:-1" -q:v 50 public/hero-custom-400.webp
  - MP4 → WebM (animation recommended):
    ffmpeg -i public/hero-video-with-audio.mp4 -c:v libvpx-vp9 -b:v 0 -crf 30 -an -vf "scale=800:-1" public/hero-video-800.webm
  - MP4 → GIF (palette method, if needed):
    ffmpeg -i public/hero-video-with-audio.mp4 -vf "fps=15,scale=800:-1:flags=lanczos,palettegen" -y public/palette.png
    ffmpeg -i public/hero-video-with-audio.mp4 -i public/palette.png -filter_complex "fps=15,scale=800:-1:flags=lanczos[x];[x][1:v]paletteuse" -y public/hero.gif
